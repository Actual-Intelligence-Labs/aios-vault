# Tasks

To-dos with no deadline. Real, but not urgent.

This file gives Claude an honest place for "someday" items, so it never invents a calendar slot for something that does not need one. Anything with a real date goes on your calendar. Anything that belongs to one project can also live in that project's note, but the to-do itself goes here so it shows up when a session starts.

## The format (the session pulse reads it)

Each to-do is one line under **Open**: an empty checkbox, the to-do in plain words, the date it was added, and a link to the note it belongs to, if there is one. For example: `- [ ] Ask Sam for the signed scope (added 2026-03-04) [[projects/acme-corp]]`.

- When a session opens, the session pulse shows Claude the first few open to-dos, so keep the ones that matter most near the top.
- When a to-do is done, tick its box (`[x]`), add the date it was done, and move it under **Done**.
- When a note's status changes (signed, sent, paid, lost), Claude closes the matching to-do here in the same turn.
- Keep any other text out of the **Open** section. The pulse reads checkbox lines only.
