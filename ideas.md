# Ideas

A holding pen for ideas that have no project yet.

If an idea clearly belongs to something you are already working on, it goes in that project's note instead, next to the work. This file is only for the good thought with nowhere to sit yet.

One line per idea, newest at the bottom, starting with the date it came up (`YYYY-MM-DD`), in your own words. Add a `[[link]]` if it touches a note.

Skim it now and then. An idea that keeps coming back usually deserves a note of its own: say "start a note for this".
