# Inbox

Every thought Claude captures gets one line here, so nothing is ever silently lost.

This file is a log, not a storage bin. The thought itself lives wherever it was routed: a project note, your calendar, `tasks.md`, `decisions/log.md`, `memory/taste.md`, `context/`, or `ideas.md`. The line here only records what was said and where it went.

One line per capture, newest at the bottom, under **Log**, in this shape: `- YYYY-MM-DD HH:MM - what was said -> where it went`. For example: `- 2026-01-15 09:42 - Send the revised scope before Friday -> [[projects/acme-corp]]`. When a session opens, the session pulse shows Claude the latest few lines, which is how a new session knows what you said in passing yesterday.

You should rarely need to read this. It is here so you can always answer "where did that go?"
